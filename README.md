# Préstamos de biblioteca

Ejecutá `python main.py` desde la carpeta que contiene `main.py` y `estado_biblioteca.json`.

El menú permite administrar usuarios y materiales, registrar préstamos de 1 a 5 horas, consultar el historial y la disponibilidad, y registrar devoluciones para liberar unidades.

El programa guarda los cambios en `estado_biblioteca.json` y los recupera al iniciar.
